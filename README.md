# Videojuego Mateo · demo

Demo jugable en el navegador de un juego 2D de acción y plataformas. Se juega en el celular, en horizontal.

**Jugar:** https://gilbertomonroy67.github.io/atomic-/

## Controles
- ◀ ▶: moverse
- SALTO: saltar; mantenlo en el aire para volar mientras dure la barra de vuelo
- GOLPE: puñetazo con bola de fuego (también puedes caerles encima a los enemigos)
- Teclado: flechas, espacio y X

## Archivos
- `index.html`: el juego completo en un solo archivo (sprites embebidos).
- `plantilla.html`: el mismo código con `__SPRITES__` en lugar de las imágenes, más fácil de leer.
